راهنمای نمونه موبایل
این بسته نمونه رابط کاربری است و به ERPNext یا سرور وصل نیست.
برای میزبانی رایگان:
1) یک مخزن عمومی در GitHub بسازید.
2) فایل‌های داخل این پوشه را در ریشه مخزن بارگذاری کنید.
3) در Settings > Pages، گزینه Deploy from a branch را انتخاب کنید.
4) Branch=main و Folder=/(root) را انتخاب و Save کنید.
5) پس از انتشار، آدرس GitHub Pages را با Chrome اندروید باز کنید.
6) از منوی سه‌نقطه Chrome گزینه Add to Home screen را بزنید.
اطلاعات سفارش در localStorage همان مرورگر ذخیره می‌شود؛ با پاک‌کردن داده‌های سایت ممکن است حذف شود.
این نسخه برای نمایش و تست فرم است؛ موجودی و قیمت‌ها نمونه‌اند و حسابداری/انبار واقعی انجام نمی‌دهد.
